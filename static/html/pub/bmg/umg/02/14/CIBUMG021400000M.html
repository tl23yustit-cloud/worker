인수인계

인수인계 구분

인수인계 구분 선택
이용안내
  • 인수인계는 기존 사용자의 계좌권한, 카드권한, 메뉴권한을 다른 사용자에게 인수인계하는 기능입니다.
  • 일반사용자는 일반사용자에게, 결재사용자는 결재사용자에게 인수인계가 가능합니다.
  • 인수인계의 종류는 인계자→인수자와 인계자↔인수자의 2가지가 있습니다.
  • 인계자→인수자를 선택하면 인계자의 권한을 인수자에게 인수인계합니다.
  • 인계자↔인수자를 선택하시면 두 사용자의 권한을 서로에게 인수인계합니다.
  • 각 사용자별 결재선은 인수인계 대상에서 제외됩니다.
