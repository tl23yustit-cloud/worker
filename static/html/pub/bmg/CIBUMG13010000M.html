임시 그리드 영역
이용안내
  • 부재설정을 한 경우, 결재선에서 제외됩니다.
  • 필수결재자의 경우 반드시 대리결재자를 등록해야 합니다.
  • 대리결재자 등록 전 거래는 해당 사용자에게 결재요청되며, 대리결재자 등록 후 기안에 한해서 대리결재자가 결재처리 할 수 있습니다.
  • 대리결재 등록 시 일반사용자의 경우 일반사용자, 결재사용자의 경우 결재사용자만 가능합니다.
  • 대리결재자 등록 시 다른 사용자의 대리결재자로 등록되어 있거나, 부재설정 중인 사용자와 동일한 결재선에 존재할 경우 등록이 불가합니다.
  • 부재설정 또는 대리결재자 해제 이전의 거래는 이전 대리결재자에게 결재요청되며, 해제 이후의 기안에 한해서 해당 결재자에게 결재 요청 됩니다.
  • 부재해제와 동시에 대리결재자가 해제 되며, 해당 사용자의 모든 결재선이 부재설정 이전의 상태로 됩니다.
  • 기안이 진행 중인 건이 있을 경우에는 부재설정이 불가합니다.
