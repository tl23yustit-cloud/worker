엑셀처럼 칸을 합쳐서 표를 만든 뒤, 아래 HTML을 복사해 화면에 붙이면 됩니다.

기존 HTML 생성기

이렇게만 하면 됩니다

  1. 1비슷한 표 고르기

    아래 버튼 중 시안이랑 제일 비슷한 걸 누릅니다. 빈 표부터 시작하지 마세요.

  2. 2칸 안의 글만 고치기

    표 칸을 클릭하고 글을 바꿉니다. 칸을 합치려면 여러 칸을 드래그한 뒤 칸 합치기를 누릅니다.

  3. 3HTML 복사해서 붙이기

    맨 아래 HTML 복사를 누른 다음, 작업 중인 화면 파일에 붙여 넣습니다.

1. 표 모양 고르기

시안이랑 똑같이 안 맞아도 됩니다. 가까운 걸 고른 뒤 글과 칸만 고치면 됩니다.

더 자세한 설정 (보통 안 눌러도 됩니다)

2. 글 고치고 칸 합치기

회색 칸 = 제목(th), 흰 칸 = 내용(td). 칸을 합치려면 마우스로 여러 칸을 문지르듯 드래그한 다음 칸 합치기를 누르세요.

지금 고른 칸

칸을 클릭하세요.

칸 종류 / 정렬 (필요할 때만)

자동이면 됩니다. 위쪽 제목은 col, 왼쪽 제목은 row, 칸을 합치면 colgroup/rowgroup이 복사 코드에 붙습니다.

3000원, 3,000, 3000,000, USD는 자동으로 text-right가 붙습니다. 그냥 3000만 쓰면 위 체크를 켜세요.
