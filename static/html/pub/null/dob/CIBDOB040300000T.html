증명서 검증(진위확인) 프로그램이란?

고출력된 증명서의 2D바코드를 이용하여 오프라인에서도 스캐너를 이용하여 증명서의 위/변조 여부를 확인할 수 있으며, 복사방지 코드를 이용하여 원본 증명서인지 복사된 증명서인지를 확인 가능한 프로그램 입니다.

프로그램 설치방법 안내

  1. 1
    지원범위
    • “[MarkAny] e-PageSAFER_검증프로그램.zip” 파일을 C:\ 아래에서 압축해제합니다.
    • “DetectorX.exe”를 실행하여 설치과정을 진행합니다.
  2. 2
    검증 프로그램 실행
    • 다운로드 받은 검증 프로그램을 더블 클릭하여 실행합니다.
  3. 3
    설치 선택
    • 프로그램을 설치할 위치를 선택하고 [설치] 버튼을 클릭합니다.
  4. 4
    확인 선택
    • 설치가 완료된 후 [확인] 버튼을 클릭합니다.
  5. 5
    확인 선택
    • 정상적으로 설치가 완료되면 바탕화면에 검증 프로그램의 바로가기가 생성됩니다.

프로그램 삭제방법 안내

  1. 1
    검증프로그램 삭제
    • [Uninstall.exe] 항목을 선택하여 검증 프로그램을 삭제합니다.
    • 32bit: C:\Program File\DetectorX_NOAX
    • 64bit: C:\Program File (x86)\DetectorX_NOAX
  2. 2
    삭제 선택
    • 아래와 같이 삭제를 확인하는 창에서 [삭제 ]버튼을 클릭합니다.
  3. 3
    확인 선택
    • 삭제가 완료되면 [확인] 버튼을 클릭하여 삭제 프로그램을 닫습니다.

검증절차 안내

  1. 1
    위·변조 방지 검증프로그램 실행
    • 바당화면의 "위·변조 방지 검증프로그램"을 더블클릭하여 실행합니다.
    • 스캐너선택
    • 현재 시스템에 연결되어 있는 스캐너를 선택하는 버튼입니다.
    • 여러 개의 스캐너나 드라이버가 설정되어 있는경우 스캐너를 선택한 후 선택버튼을 누릅니다.
    • 증명서 검증
    • 이미지를 스캔하여 그 이미지가 올바른 문서임을 비교할 수 있도록 해주는 기능을 말합니다.
    • 스캔 한 이미지에서 2차원 바코드를 읽어낸 후 원본을 추출하여 스캔 한 이미지와 2차원 바코드의 복원 데이터를 함꼐 보여줌으로써 비교 가능하도록 구성되어있으며 이를 통해 위·변조 여부를 확인할 수 있습니다.
  2. 2
    스캐너 선택
    • [스캐너 선택]버튼을 클릭하여 연결된 스캐너를 선택합니다.
    • 만일 스캐너 사용 시 아래와 같이 오류메세지가 나타난다면 스캐너를 다른 프로그램에서 사용하고 있거나, 연결되어있는 스캐너와 원본 선택이 맞지 않아서 나타나는 경우가 있습니다.
    • 그런 경우 올바른 스캐너를 위와 같이 선택하십시요.
  3. 3
    증명서 검증 선택 및 결과 확인
    • [증명서 검증] 버튼을 클릭하여 발급문서의 위·변조 여부를 판단합니다.
    • 인터넷으로 발급된 웹 민원서류의 위·변조 방지를 위한 기능으로 위조 혹은 변조되었을 경우 문서의 2차원 바코드를 읽어내어 원본과 비교함으로써 위·변조 된 부분을 비교 확인 할 수 있는 기능입니다.
    • 2차원 바코드를 복원하기 위해 [증명서 검증]버튼을 눌려 스캔합니다.
    • 스캔이 끝나면 2차원 바코드에서 전자서명을 검증합니다.
    • 전자서명에 대해 검증이 끝나면 아래와 같은 검증확인 메세지가 문서의 발급시간과 함께 화면에 표시됩니다.
    • 바코드에서 추출된 원본 문서와 스캔 된 이미지가 화면에 표시됩니다.
    • ㅂ스캔 된 문서와 2D 바코드로부터 추출된 원본 문서를 서로 비교하여 발급문서의 위·변조 여부를 판단합니다.
