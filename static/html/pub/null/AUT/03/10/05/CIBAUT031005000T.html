스마트폰인증서복사

스마트폰으로 내보내기 탭

공동인증서 스마트폰으로 내보내기

고객님의 안전한 전자금융거래와 보안성 강화를 위해 공동인증서를 기반으로 서비스를 제공합니다.

  • 스마트폰 기반 모바일뱅킹 서비스를 이용하기 위해서는 PC에 발급된 고객님의 공통인증서를 스마트폰으로 ‘복사’하여야 합니다.
  • 인증서 복사를 위해서는 ‘공동인증서 스마트폰으로 내보내기‘ 버튼을 클릭한 후 진행하여 주시기 바랍니다.

PC에 있는
인증서 내보내기

  1. 1
    [공통인증서 스마트폰 내보내기]버튼 클릭
  2. 2
    공동인증서 선택
  3. 3
    공인인증서 암호 입력
  4. 4
    생성된 인증번호 확인

Phone으로
인증서 가져오기

  1. 5
    '인증센터'선택 후 인증서 가져오기를 실행
  2. 6
    PC에서 생성된 비밀번호 입력 후 '인증서 가져오기'버튼을 선택
  3. 7
    인증서 가져오기 완료

[PC]인증서 내보내는 방법 안내

  1. STEP 01

    인증센터>스마트폰 인증서 복사로 이동후[공동인증서 스마트폰 내보내기]버튼을 클릭

  2. STEP 02

    스마트폰으로 복사할 공동인증서 선택후 암호입력

  3. STEP 03

    인증번호 출혁 확인

[Phone]인증서 가져오는 방법 안내

  1. STEP 01

    수협은행App을 실행>공인인증센터>인증서 가져오기 선택

  2. STEP 02

    생성된 인증번호 입력 후 [인증서 가져오기] 버튼을 선택

  3. STEP 03

    인증서 가져오기 완료

PC로 가져오기 탭

공동인증서 PC로 가져오기

스마트폰에 저장되어 있는 공동인증서를 PC로 가져오기 위한 서비스 입니다.

  • 인증서 복사를 위해서는 스마트폰 앱 인증센터 > 공동인증서 > 인증서내보내기 메뉴에서 내보낼 인증서를 선택하신 후 인증서 암호 입력 하시면 인증번호 8자리가 생성 됩니다.
  • PC아래의 ‘공동인증서 PC로 가져오기’ 버튼을 클릭한 후 스마트폰 화면에 생성된 인증번호 8자리를 입력하시고 다음을 진행하시면 됩니다.

Phone에서
인증서 내보내기

  1. 1
    인증센터 선택 후 '인증서 내보내기'실행
  2. 2
    공동인증서 선택
  3. 3
    공동인증서 암호 입력
  4. 4
    인증번호 생성

PC로
인증서 가져오기

  1. 5
    '공동인증서 PC로 가져오기' 버튼 클릭 후'인증번호 생성'에서 [다음]클릭
  2. 6
    인증번호 입력
  3. 7
    저저장할 매체 선택 후 인증서 암호 입력 후 확인 버튼
  4. 8
    인증서 가져오기 완료

[Phone]인증서 내보내는 방법 안내

  1. STEP 01

    인증센터>인증서 내보내기 메뉴 선택

  2. STEP 02

    PC로 내보낼 인증서를 선택하고 인증서 암호를 입력

  3. STEP 03

    인증번호 출력 확인

[PC]인증서 암호 입력 방법 안내

  1. STEP 01

    인증센터>스마트폰인증서 복사 > PC로 가져오기 버튼을 클릭

  2. STEP 02

    [공통인증서 PC로 가져오기]버튼을 클릭

  3. STEP 03

    스마트폰에서 생성된 인증번호를 입력 후 [다음] 버튼을 클릭

  4. STEP 04

    저장매체 선택

  5. STEP 05

    인증서 암호 입력후 [확인]버튼 클릭

  6. STEP 06

    인증서 가져오기 완료

QR코드로 스마트폰에 내보내기 탭

QR코드로 스마트폰에 보내기

QR코드로 복사하기는 PC에 생성된 사각형 바코드(QR코드)를 스마트폰으로 촬영하여 인증서를 복사하는 방식입니다.

PC에 있는
인증서 복사하기(보내기)

  1. 1
    [공동인증서 QR코드로 스마트폰에 보내기]버튼 클릭
  2. 2
    공동인증서 선택
  3. 3
    공동인증서 암호 입력
  4. 4
    PC에서 QR코드 생성 완료

Phone으로
인증서 가져오기(요청)

  1. 5
    '인증센터'선택 후 '인증서 QR코드로 복사하기'실행
  2. 6
    [인증서 가져오기]버튼 선택하여 QR코드 인식카메라 실행
  3. 7
    PC에서 생성된 QR코드를 스마트폰으로 인식
  4. 8
    인증서 가져오기 완료

[PC]인증서 복사하는 방법 안내

  1. STEP 01

    인증센터>PC>스마트폰 QR코드로 복사하기>공동인증서 스마트폰으로 보내기 클릭

  2. STEP 02

    스마트폰으로 복사할 공동인증서 선택

  3. STEP 03

    우측화면에 QR코드가 생성된 표시 확인

[Phone]인증서 가져오는 방법 안내

  1. STEP 01

    인증센터>인증서 QR코드로 복사하기 메뉴 선택

  2. STEP 02

    '인증서 가져오기'버튼을 선택하여 QR인식 카메라 실행

  3. STEP 03

    PC에서 생성된 QR코드를 스마트폰 QR스캔 화면 선 안에 맞추어 인증서 복사 실행

  4. STEP 04

    스마트폰으로 이동할 인증서가 맞는지 여부를 확인

  5. STEP 05

    스마트폰에서 '인증서 가져오기 완료'메세지가 나오면 [확인] 버튼을 클릭하여 스마트폰 뱅킹 메인 화면으로 이동
