결제계좌 변경

OTP 비밀번호 입력
공통UI 적용
이용안내
  • 결제계좌를 변경 할 수 있는 화면입니다.
  • 개인사업자의 경우 대표가 개인계좌로도 변경가능힙니다.
  • 저축은행은 BC사와 제휴되어 있지 않아 결제계좌 등록이 불가능합니다.
  • 주류구매전용카드는 결제계좌변경이 불가합니다.
  • 결제계좌 변경은 가능일은 아래와 같습니다.
    • 변경 가능일 : 1일 ~ 25일 중 7, 8, 9, 16, 17, 18일을 제외한 일자중 선택 가능
    • 변경 가능시간 : (평일) 04:00 ~ 22:00
    • 변경 제한 : 1일 1회 변경가능
  • 결제일 1영업일전까지 변경 가능하나 해당 결제일에 결제금액이 없는 경우 제한없이 변경가능합니다.
  • 수협→수협계좌로 변경 시, 현금카드 겸용 예금인출 기능은 영업점으로 내점하여 등록 후 이용 가능합니다.
  • 타행맞춤계좌는 결제계좌로 이용이 불가합니다.
